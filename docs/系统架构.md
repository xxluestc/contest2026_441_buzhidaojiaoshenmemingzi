# 系统架构

## 核心数据链

```text
用户按键/语音触发
        │
        ▼
Camera Service ── V4L2 /dev/video0 ── 单帧 JPEG
        │
        ▼
Vision Service ── Wi-Fi + HTTPS ── MiMo Vision
        │                              │
        └──── 有界结构化结果 ◀─────────┘
                       │
          ┌────────────┼────────────┐
          ▼            ▼            ▼
       控制台       TTS/I2S      GPIO/PWM 振动
      （M6 基线）   （第二阶段）   （第二阶段）
```

## 模块责任

| 模块 | 输入 | 输出 | 当前状态 |
| --- | --- | --- | --- |
| `workflow` | 用户问题、图像/结果缓冲 | 阶段和错误码 | 状态机骨架已完成 |
| `camera_service` | V4L2 设备路径、图像缓冲 | 单帧 JPEG | 节点探测已完成，取帧待 M3/M4 |
| `vision_service` | JPEG、用户问题 | 有界文本/方向提示 | 接口已完成，HTTPS/MiMo 待 M5 |
| `audio_service` | PCM 缓冲 | 录音长度 | 节点探测已完成，录音待 M7 |
| `feedback_service` | 结构化结果 | 控制台/音频/振动 | 控制台基线已完成，其余待 M6/M9 |

所有服务采用负 errno 返回失败，`workflow` 保留失败发生的阶段。当前未实现后端统一返回 `-ENOSYS`，避免调用方把占位实现当成功。

## 运行约束

- 每次只处理一个用户请求和一张图，第一阶段不并发上传多帧；
- 图像、TLS 和 JSON 大缓冲错峰使用，真实峰值以真机测量为准；
- 请求和响应必须设置尺寸、连接和读取超时；
- API Key、Wi-Fi 密码和私钥不编译进固件、不进入仓库或 AI 日志；
- 云端不可用时返回明确错误并给出本地状态反馈，不生成伪答案。
